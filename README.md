# Trading Strategy Dashboard

ML-enhanced trading strategy dashboard with performance analytics.

## Features
- Interactive candlestick charts with entry/exit markers
- Equity curve vs buy & hold comparison
- Drawdown analysis
- Annual performance metrics (2023-2025)
- Trade-level analytics

## Installation
```bash
pip install -r requirements.txt
```

## Usage
```bash
streamlit run app.py
```

## Data
Place your parquet files in the `data/` folder.
